9. Zephyr Insulation

Core positioning

Lightweight by nature. Powerful by design.

Zephyr is positioned as a highly porous and ultra-lightweight insulation material with thermal insulating characteristics.

Its lightweight and flexible characteristics allow it to be considered for applications where thermal protection needs to be integrated without significant additional weight.
